# Stintmate IPC

Stintmate IPC v2 is the protocol the Stintmate apps and connectors talk over: Windows named
pipes, MessagePack frames, an authenticated handshake with a per-user key file, calls,
events, state and stream channels. The protocol is defined in [`SPEC.md`](SPEC.md); the
byte-exact test vectors are in [`vectors/`](vectors/).

This repository holds the reference implementation, written in Rust, and its product: the
native library `stintmate_ipc.dll` with its header `crates/stintmate-ipc-ffi/include/stintmate_ipc.h`. Every language,
Python included, uses the DLL through the C ABI. This repository contains no Python package and
no examples.

| Path | What |
|---|---|
| `crates/stintmate-ipc/` | the core library (Rust API, async on Tokio, plus a blocking facade) |
| `crates/stintmate-ipc-ffi/` | the C ABI: `stintmate_ipc.dll`, header `include/stintmate_ipc.h` generated by cbindgen, MessagePack payloads |
| `crates/stintmate-ipc-check/` | `stintmate-ipc-check`, the conformance tool |

## Building

Requirements on Windows: Rust (the version in `rust-toolchain.toml`, installed by rustup) with
the MSVC target and the Visual Studio Build Tools C++ workload.

```
cargo build --release -p stintmate-ipc-ffi   # target/release/stintmate_ipc.dll
cargo build --workspace                      # also builds the DLL the FFI tests load
cargo test --workspace
```

The header is generated by the build and committed (`crates/stintmate-ipc-ffi/include/`).

## The C ABI

The ABI is versioned apart from the crate (ABI 1.0 with crate 0.3.0): MAJOR changes on any
removal, rename, signature or meaning change; MINOR grows when functions, constants, struct
fields at the end or MessagePack map keys are added. A caller accepts a DLL with the same
MAJOR and a MINOR at least its own (`stintmate_ipc_abi_version()`). The rules (return codes,
buffer ownership, handles, callbacks and threads, `user_data` and `release`, structs with
`struct_size`, timeouts, panics, strings, shutdown) are the comment at the top of
[`stintmate_ipc.h`](crates/stintmate-ipc-ffi/include/stintmate_ipc.h). A test pins every
exported symbol and its signature (`crates/stintmate-ipc-ffi/tests/abi_baseline.txt`).

## The conformance checker

`stintmate-ipc-check` checks an implementation (client or server) against the protocol. Commands:
`server <pipe>`, `client <pipe>`, `list` (the workspace's endpoint registry) and `keygen [path]`;
`--help` prints every option. It exits 0 when every check passed, 1 when one failed, 2 on a usage error.

```
cargo run --release -p stintmate-ipc-check -- --help
```
