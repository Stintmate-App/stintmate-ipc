## Findings against plan 3.1 (T6, 2026-10-23)

Added to the binding in T6 (not in 3.1): `Event` and `Sample` (subscribers read `.data`, `.snapshot`,
`.seq`, `.body`, `.t_ns`, `.values()`), `Subscription` (`Peer.subscribe`), `Peer.run`,
`Peer.close_code`, `Peer.close_message`, `Peer.decl` (a wire-form dict for now; the `decl`
classes are T7), `Client.connect(timeout)`, `Client.last_error`, `Client.on_connect_error`
(settable callable; the skeleton connector uses it), `Client(reconnect=False)` (tests),
`RemoteError.details` (an alias of `data`; Pitwall and Speech pass `details=`), `connect(timeout=, node=)`.

For T7 or the app tasks:

- `connect(..., node=client)` is used by the AMS2 connector's own reconnect loop to hand a
  `Client`'s methods and channels to a single connection. T6 accepts and ignores `node`; T7 must
  decide (offer the node's methods on that connection, or the connector moves to `Client`).
- The AMS2 connector subclasses `Client` and overrides `reconnect_delay` (works: `Client` is
  subclassable and the method is plain Python), but the Rust client's own loop does not call
  the override; the connector calls `node.reconnect_delay(code, attempt)` itself, so it works.
  A core hook for a custom policy is only needed if an app relies on the override inside `start()`.
- `ams2_connector/ipc.py` declares `KeySource = bytes | Callable[[], bytes]`: a callable key is
  still accepted by its own code; the binding accepts `KeyFile` or 32 bytes only (3.2).
- `Context` is used as a type only in Pitwall's server; `Peer`/`PendingCall`/`ClientSubscription`
  as types in Pitwall (exported).
- Tests use `stintmate_ipc.decl.EVENT/STATE/STREAM`, `check.cli.main`, `Endpoint(pipe=, registry=,
  heartbeat_ms=)`, `Endpoint.peers`, `on_active`, `on_subscribe`, `Context.wait_cancelled`,
  `Context.progress(extend_s=)`: all T7.
- `RemoteError.from_wire/to_wire`, `PeerInfo.to_wire/from_wire`: not used by any app; not provided.
- `naming.*` helpers (`ascii_lower`, `split_pipe`, `endpoint_id`, `valid_name`) are used only by the
  old package's tests; not provided.
